#KnowUrLLM 

KnowUrLLM is an interactive DSC 106 final project that delves into what an LLM thinks about when reading text. By employing freely available GPT-2 feature data from Neuronpedia alongside sparse autoencoders, the project illustrates how automatic feature labels can both assist and confound users’ interpretation of model features.
 By providing examples such as “cats” being triggered by the word “cataracts,” the project emphasizes how labels do not necessarily convey what a model feature reacts to. The readers will be taken through scrollable visual explanations that highlight how feature labels, activation text, and context differ.
 In the course of this project, some of the interactive visualizations employed include a scrollable story, a dot map, a heatmap, a histogram, and a word-matching graph. This project was created using D3.js for DSC 106 and is hosted on GitHub Pages. Locally: python3 -m http.server 8000 Then visit: http://localhost:8000
